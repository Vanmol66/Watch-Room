# Contributing to Watch Room

Thank you for your interest in contributing to Watch Room! 🎬

Watch Room is an open-source peer-to-peer video synchronization application built with HTML, CSS, JavaScript, WebRTC, and PeerJS.

We welcome bug fixes, improvements, documentation updates, UI improvements, and new features.

## 🚀 Getting Started

### 1. Fork the repository

Click the **Fork** button on GitHub to create your own copy of Watch Room.

### 2. Clone your fork

```bash
git clone https://github.com/YOUR_USERNAME/Watch-Room.git
cd Watch-Room
